# AlReaderX Bridge for KOReader

Плагин KOReader для синхронизации позиции чтения с **AlReaderX** через локальные файлы или WebDAV. Поддерживает двустороннее преобразование текстовых координат **FB2 и EPUB** и защищённый экспорт позиции. Дополнительно предлагает пункты меню для резервного копирования и восстановления конфигурации KOReader через отдельный плагин [Device Backup & Restore](https://github.com/ultimatejimmy/backup.koplugin).

> **Статус: экспериментальная версия 1.4.0.** Тесты проведены на настоящих движках AlReaderX 1.33 и KOReader Android: несколько FB2, EPUB с двумя главами, EPUB с вложенными блоками и обратный переход EPUB → AlReaderX. На физическом Kindle 1.4.0 ещё не проверена. Не все разновидности EPUB верифицированы, поэтому неподтверждённые конструкции отклоняются без записи позиции.

## Установка — стандартная для KOReader

1. Скачайте ZIP релиза, содержащий **ровно одну папку** `alreaderbridge.koplugin`. Или скачайте исходники (`Code → Download ZIP`) и найдите в них эту папку.
2. Полностью закройте KOReader и подключите устройство к компьютеру.
3. Скопируйте **папку целиком** в каталог `koreader/plugins/` на устройстве. На Kindle это обычно `koreader/plugins/` в корне USB-диска; на Android — `Внутренняя память/koreader/plugins/`.
4. Проверьте структуру: `koreader/plugins/alreaderbridge.koplugin/main.lua` (НЕ `plugins/alreaderbridge.koplugin/alreaderbridge.koplugin/main.lua`).
5. Безопасно извлеките устройство и **полностью перезапустите KOReader**. Плагин появится в меню **AlReaderX Bridge v1.4.0**, когда открыта книга.

Для установки достаточно скопировать папку плагина: дополнительные установщики и скрипты не нужны. Подключение к серверу требуется только для сетевой синхронизации через WebDAV. Не меняйте исходные файлы KOReader.

## Настройка позиции чтения

1. На AlReaderX настройте файловый обмен или свой HTTPS WebDAV и отправьте позицию по штатной команде приложения.
2. В KOReader откройте ту же книгу. Для FB2 требуется совпадение исходного файла и имени; для EPUB — совпадение имени файла и уникального UUID книги в OPF.
3. В меню **AlReaderX Bridge** заполните **WebDAV: адрес каталога**, **логин**, **пароль**. Указывайте WebDAV-корень, в котором AlReaderX хранит папку `AlReaderX-01Sync` (плагин также ищет несколько старых вариантов). Для локального обмена скопируйте исходный файл позиции в `koreader/alreaderx-sync/`.
4. Выберите **Импортировать позицию сейчас**. При первом переходе подтвердите предложение. Дальше доступен автоматический импорт при открытии книги.
5. **Отправить текущую позицию** — ручной экспорт на WebDAV. Автоэкспорт при закрытии включается отдельно в меню. Предварительно проверьте обратный переход на тестовой книге.

**Поддерживаемые форматы (v1.4.0):**
- `.fb2` и `.fb2.zip`: UTF-8, Windows-1251, KOI8-R, CP866, ISO-8859-5, Windows-1252, ISO-8859-1; UTF-16 LE/BE (BOM). Проверены на обоих движках обычный текст, таблицы, изображения, вложенные стили, верхние/нижние индексы и ссылки. Редкие нестандартные XML-конструкции ещё не исследованы.
- `.epub`: EPUB без DRM с UUID в OPF, XHTML-главами, обычными абзацами, заголовками и проверенными inline-выделениями. Два EPUB проверены на обоих движках. Пока отклоняются EPUB с таблицами, встроенными изображениями, ruby, нетипичным CSS и служебной разметкой, для которых не сверена внутренняя нумерация AlReaderX.

**Прочие ограничения и безопасность:** DRM требует, чтобы обе программы имели разрешённый доступ к книге: плагин не расшифровывает защищённый контент. Штатный `kosync` остаётся независимым механизмом, и это не мешает работе моста. Перед первым обменом сохраните каталог `Sync`: независимые записи других AlReaderX плагин не контролирует. Учётные данные WebDAV хранятся в настройках KOReader без шифрования *на диске*: HTTPS защищает передачу, но не является сквозным шифрованием содержимого.

## Резервные копии KOReader, шрифты и стили

Дополнительный компонент **не входит в этот репозиторий** и устанавливается стандартно: откройте [backup.koplugin](https://github.com/ultimatejimmy/backup.koplugin), скачайте архив плагина и скопируйте **его** папку `backup.koplugin` в `koreader/plugins/`; перезапустите KOReader.

После этого пункты в AlReaderX Bridge вызывают функции Device Backup & Restore: создание архива, восстановление, просмотр локальных/облачных копий и настройку расписания. Для WebDAV резервных копий: сначала заполните **WebDAV: адрес резервных копий** (свой HTTPS WebDAV), затем **Настроить WebDAV резервных копий**. Можно выбрать шрифты (`fonts/`), пользовательские стили (`styletweaks/`), настройки, плагины, профили, жесты и историю.

Архив конфигурации — **снимок**, не одновременное слияние настроек в обе стороны. Восстановление следует применять вручную после просмотра состава и резервного снимка; некоторые привязанные к железу настройки не стоит переносить между платформами без cross-device sanitization. Не публикуйте архив с паролями.

## Структура исходников

```text
alreaderbridge.koplugin/
  _meta.lua       # метаданные KOReader
  main.lua        # меню, события, импорт/экспорт и резервные копии
  core.lua        # разбор Sync и идентификация книг
  positionmap.lua # FB2 ↔ XPointer
  epubmap.lua    # EPUB spine ↔ XPointer and book identity
  charset.lua    # XML byte encoding conversion
  dav.lua         # WebDAV операции
tests/
  fixture.fb2     # синтетическая книга
  test_core.lua
  test_positionmap.lua
  test_native_engine.lua
  test_epubmap.lua
  run.sh
```

**Тесты:** `./tests/run.sh` на системе с LuaJIT. Они подтверждают поведение конвертера на синтетической контрольной FB2, но не заменяют приёмку на Kindle. Код плагина под MIT; Device Backup & Restore — отдельный upstream-проект со своей лицензией.

Подробная инструкция: [docs/INSTALL_RU.md](docs/INSTALL_RU.md).
