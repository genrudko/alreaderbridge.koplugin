# Установка и использование AlReaderX Bridge

## 1. Плагин для KOReader

Скачайте архив релиза, распакуйте его и скопируйте каталог `alreaderbridge.koplugin` в `koreader/plugins` на USB-диске Kindle. Аналогично на Android и других устройствах, где установлен KOReader. Должен существовать файл `koreader/plugins/alreaderbridge.koplugin/main.lua`. Полностью перезапустите KOReader.

При скачивании **Code → Download ZIP** GitHub создаёт обёртку с именем репозитория: скопируйте именно внутреннюю папку `alreaderbridge.koplugin`, а не весь архив целиком.

## 2. Подключение AlReaderX

Используйте штатный файловый обмен AlReaderX (локальный режим или WebDAV). Для ручного импорта скиньте файл позиции в `koreader/alreaderx-sync`. Для сети в AlReaderX Bridge заполните `WebDAV: адрес каталога`, логин и пароль. HTTPS обязателен. Директория позиций обычно `AlReaderX-01Sync` под указанным корнем.

Откройте ту же FB2, FB2.zip либо поддерживаемую EPUB на Kindle, выполните `Импортировать позицию сейчас`. При первом импорте подтвердите переход. Экспорт текущей позиции выполняется отдельной кнопкой. На первом этапе включайте автоэкспорт только после тестового обратного перехода и резервирования оригинальных файлов Sync.

Проверить соединение можно командой `Проверить подключение WebDAV`. Ошибки несовпадения книги не обходите принудительно: если байты книг отличаются, координаты могут оказаться несовместимыми.

## 3. Резервирование KOReader

Для архива настроек дополнительно установите [Device Backup & Restore](https://github.com/ultimatejimmy/backup.koplugin), тоже копированием папки `backup.koplugin` в `koreader/plugins`, затем перезапустите программу. Шрифты пользователя — `fonts/`, CSS-стили — `styletweaks/`, настройки — `settings.reader.lua` и файлы в `settings/`. Ставьте галочки на нужных компонентах при создании резервной копии.

Чтобы загружать архивы в облако, настройте HTTPS URL резервного WebDAV отдельным пунктом в AlReaderX Bridge и подтвердите подключение. Адрес и учётные данные хранятся на устройстве KOReader, в обычных файлах настроек. Восстанавливайте архив вручную, предварительно сохранив локальный снимок и проверив аппаратно-зависимые настройки. После восстановления перезапустите KOReader.

## 4. Обновление и удаление

Полностью закройте KOReader, сохраните старую папку `alreaderbridge.koplugin` на компьютер, затем замените её новой папкой из архива. Настройки остаются в каталоге данных `koreader/settings` и не исчезают при замене плагина. Для отката верните прежнюю папку, перезапустите KOReader.

Удаление: закройте KOReader и удалите `koreader/plugins/alreaderbridge.koplugin`; данные и настройки удаляются отдельно, только при необходимости.

## 5. Безопасность и ограничения

- Совместимость: FB2, FB2.zip и проверенный XHTML-EPUB без DRM. Для EPUB требуется идентификатор UUID в OPF; сложная CSS-разметка, таблицы, изображения и нестандартные HTML-элементы пока отклоняются.
- FB2: кроме UTF-8 поддерживаются Windows-1251, KOI8-R, CP866, ISO-8859-5, Windows-1252, ISO-8859-1 и UTF-16LE/BE. Проверена нумерация AlReaderX для таблиц, изображений, выделений, ссылок и индексов.
- Не храните пароль WebDAV в репозитории. Сетевую синхронизацию включайте только через доверенный HTTPS-сервер.
- Никогда не заменяйте весь каталог `koreader/` архивом другого устройства без проверки.
- Резервное копирование и синхронизация координат — разные функции. Шрифты и стили AlReaderX через этот плагин не синхронизируются.
- См. также [официальное руководство KOReader](https://koreader.rocks/user_guide/).
